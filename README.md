# Эмулятор Virtual File System (VFS) — Этап 3: Подключение VFS

Графическое приложение на Python (Tkinter), эмулирующее работу командной строки для взаимодействия с виртуальной файловой системой (VFS), загружаемой из CSV-файла и функционирующей полностью в оперативной памяти.

## Особенности реализации

* **Работа в оперативной памяти:** Данные VFS полностью загружаются из CSV-файла в оперативную память при старте приложения. Модификация данных на диске во время работы с командами `cd` и `ls` не производится.
* **Формат хранения CSV:** Для бинарных данных внутри файлов используется кодирование `base64`. Поддерживается многоуровневая структура вложенности папок и файлов.
* **Интерактивный интерфейс:** Отображение текущего пути VFS в приглашении командной строки (например, `[vfs.csv:/home/user]$ `).
* **Сброс VFS (`vfs-init`):** Специальная команда сбрасывает состояние VFS в памяти и перезаписывает физический CSV-файл структурой по умолчанию.

## Параметры командной строки

| Параметр | Тип | По умолчанию | Описание |
| `--vfs` | `str` | `vfs.csv` | Путь к CSV-файлу с виртуальной файловой системой |
| `--script` | `str` | `None` | Путь к стартовому текстовому скрипту с командами |

## Команды


| `ls` | `[path]` | Выводит список файлов и папок в текущей или указанной директории |
| `cd` | `<path>` | Переходит в указанную директорию (поддерживаются относительные и абсолютные пути) |
| `vfs-init` | — | Сбрасывает VFS к начальному состоянию по умолчанию и обновляет CSV-файл |
| `help` | — | Выводит справочную информацию по командам |
| `exit` | — | Завершает работу приложения |
